# UFO 출현 예측 달력

`dist/index.html`을 브라우저로 열면 인터넷 연결이나 Python 서버 없이 시연할 수 있습니다. `dist`의 네 파일을 함께 보관하세요.

6개 지역의 2013년 날짜별 신고 가능성을 표시합니다. 날짜 선택, 월 이동, 추천 날짜, 시간·모양 통계, 다크 모드를 지원합니다. 방향키로 날짜를 이동하고 Enter로 선택할 수 있습니다.

상단 제목은 프로젝트명인 'UFO 출현 예측 달력'을 사용합니다. 숫자는 실제 출현률이 아닌 목격 신고 발생 확률이며, 전날까지의 실제 기록을 이용한 하루 앞 백테스트 결과입니다. 모양과 시각은 2000~2010년 같은 지역·월의 통계입니다.

Colab에서 모델 결과를 새로 만든 경우 `outputs`에 결과 파일을 교체한 후 Node.js로 `node website/prepare-data.mjs`를 실행하면 화면 데이터가 갱신됩니다. 모델은 웹페이지에서 재학습하지 않습니다.
